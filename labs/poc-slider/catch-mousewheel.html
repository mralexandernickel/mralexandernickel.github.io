Proof of Concept

Browser Tooling

In this variant we only use what the Browser already comes with. Horizontal Areas can be scrolled by holding the shift-key and use the mousewheel meanwhile. Because most people don't know of this feature, we should add some kind of "hint" when entering a slider with the mouse.

The allover scroll-behavior and performance in general is best in this variant!

Try Browser Tooling!

Catch Mousewheel

This means that we're going to catch the "mousewheel-event" when the mouse is "above" a slider. The vertical scrolling is prevented while the mouse is "on" a slider.

In this variant we don't need no explanation, but some people find this behavior a bit "disabling".

Catch The Mousewheel!

Show Arrows

Showing arrows inside each Slider means that we need to use JavaScript to generate the arrow-elements, to handle the click-events on them arrows, find out if there is content-to-scroll in each direction and finally use this information to show or hide the arrows per direction.

This variant is the most common one, but also has the worst performance!

Please Show Arrows!
